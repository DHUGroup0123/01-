# 01电商系统 第二周接口与协作交接

本文件描述feature/member-a实际实现，不表示B/C分支已经合并验证。第一周V001字段及状态语义保持不变。

## 基础约定

统一JSON：`{"code":200,"message":"操作成功","data":...}`。HTTP状态与code对齐：400参数或验证码错误，401未登录/凭据错误，403账号禁用或CSRF失效，404资源不存在或无归属，409账号重复或地址数量超限，429尝试过多，503数据库不可用。

对外业务ID均为字符串，价格为两位小数字符串。Session内部SessionUser保留Long userId以兼容C调用；JSON不直接序列化该Session对象。

## Session与CSRF

- Session键沿用SessionKeys.MALL_USER=`mallUser`，值为SessionUser(userId,loginName,nickname)。不存密码哈希或完整地址。
- 用户登录成功更换Session ID，刷新mallCsrf；退出销毁Session。用户受保护请求逐次查询当前用户status，禁用后撤销会话。
- 首先GET /api/csrf，保存data.token，写操作在请求头带`X-CSRF-TOKEN`。登录后需要重新GET取token；CSRF缺失或不匹配返回403。
- 用户、地址、购物车和订单API的POST/PUT/DELETE等非安全方法都校验token，包括注册与登录；管理员API留给B的鉴权配置。
- 受保护页面：/personal、/cart、/order、/orders、/checkout及子路径；未登录跳/login。
- 受保护API：/api/users/me、/api/users/logout、/api/addresses、/api/cart、/api/orders及子路径；未登录返回401，即使交易控制器尚未合入也先保护这些前缀。
- Session超时30分钟，cookie HttpOnly、SameSite=Lax；第三周部署需配合HTTPS和Secure cookie。

## 商品展示字段

productId、categoryId、productName、summary、coverUrl、detailText、originalPrice、sellingPrice、stock。A从B的product/category/轮播配置只读查询；公开响应不回传原始detailHtml，富文本先转成纯文本。封面仅接受/images或/uploads下的本地路径，其他值回退为/images/01-product.svg。

categoryId可为任意一级，查询同时纳入其下级商品；当前以V001三级目录为基础，分类自身及父祖先的is_deleted都须为0。商品sell_status=1是上架，0是下架。

keyword≤50，默认空；sort=latest/priceAsc/priceDesc；page默认1，范围1至100000；pageSize默认12，范围1至50。非法值返回400，超出结果末页返回空list。LIKE中的%和_作为普通字符处理，排序仅走SQL白名单，不拼接客户端SQL片段。

首页只显示is_enabled=1的轮播与商品配置，按sort_order倒序、ID稳定排序；每组最多8件，轮播最多5张。轮播链接仅允许/search或/products/{数字ID}及受限查询串。没有配置时显示空态/本地横幅，不伪造后台数据。

## 地址与C交易模块

默认地址在单个用户记录FOR UPDATE行锁下维护；有地址时保证一条默认，第一条自动默认、默认删除后选择剩余最早地址。最多20条。C下单仍必须以当前Session userId查询并核对地址归属，再保存订单地址快照，不能信任浏览器提交的userId或完整地址。

C新增前端写请求时必须先取CSRF并带头。A已经保护/api/cart及/api/orders前缀，但没有实现或修改C的交易业务。第三周联调时核对C现有Session、URL和错误格式；不能因为本次A独立测试通过就认定交易链路已通过。

## 安全实现与限制

验证码：安全随机5字符PNG，120秒有效、不区分大小写、每次校验不论对错均销毁。密码：PBKDF2-HMAC-SHA256，随机盐，600000次迭代，256位哈希，格式pbkdf2-sha256$600000$salt$hash。参考OWASP密码存储建议：https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html 。

频率限制为当前应用实例内存中的每账号10次/5分钟、每IP60次/5分钟，注册和登录共用；不信任X-Forwarded-For。它适合本课程单实例运行，不是分布式限流。没有开放密码重置、短信验证码、真实支付或第三方账号功能。
