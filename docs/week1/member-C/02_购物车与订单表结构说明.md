\# 购物车与订单核心表结构设计说明（成员C）



\## 1. 购物车表 `tb\\\_shopping\\\_cart\\\_item`

| 字段 | 类型 | 说明 |

|------|------|------|

| cart\_item\_id | Long | 购物项主键，自增 |

| user\_id | Long | 所属用户ID |

| goods\_id | Long | 商品ID |

| goods\_count | Integer | 购买数量 |

| is\_deleted | Byte | 逻辑删除标记（0正常/1已删除） |



\## 2. 订单主表 `tb\\\_order`

| 字段 | 类型 | 说明 |

|------|------|------|

| order\_id | Long | 订单主键，自增 |

| order\_no | String | 业务订单号（唯一流水号） |

| user\_id | Long | 下单用户ID |

| total\_price | Integer | 订单总价 |

| pay\_status | Byte | 支付状态（0未支付/1支付成功） |

| pay\_type | Byte | 支付方式（1支付宝/2微信） |

| order\_status | Byte | 订单状态（对应状态机枚举） |

| user\_address | String | 收货地址快照 |

| create\_time | Date | 创建时间 |



\## 3. 订单明细表 `tb\\\_order\\\_item`

| 字段 | 类型 | 说明 |

|------|------|------|

| order\_item\_id | Long | 明细主键 |

| order\_id | Long | 所属订单ID（关联主表） |

| goods\_id | Long | 商品ID |

| goods\_name | String | 商品名称快照（防止商品改名） |

| selling\_price | Integer | 成交单价快照（防止商品改价） |

| goods\_count | Integer | 购买数量 |



\*\*说明\*\*：订单主表与明细表为 1:N 关系，下订单时使用 MyBatis 的批量插入（Batch Insert）提高性能。
