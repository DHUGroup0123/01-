# 01电商系统 参考项目说明

本项目名称为“01电商系统”，在原有课程工程中独立实现。newbee-mall 作为需求分解、页面模块和分层方式的学习参考，不是把其仓库直接改名交付。

## 实现差异

- 参考项目使用旧技术栈；本项目由用户决定采用Spring Boot4 / Java17，使用Jakarta接口。
- 自行设计V001数据库、演示数据、模板、样式和本周环境接口，不下载其商城图片或导入其建库数据。
- 参考项目 Session 键、商品上架值与订单整数值不直接复用，本项目以协作接口文档为准。
- 不照搬参考项目硬编码数据库密码或MD5密码实现；本周无账号固定密码，第二周使用加盐哈希。
- 第一周只做环境、需求与约定，参考仓库的完整功能不等于本项目已经实现。
