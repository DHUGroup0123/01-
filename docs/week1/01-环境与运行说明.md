# 01电商系统 环境与运行说明

## 固定环境

| 项目 | 本项目版本或约定 |
| --- | --- |
| 操作系统 | Windows 10 / 11 |
| JDK | Java 17，IDEA Project SDK、Maven Runner JRE 均设为 17 |
| Spring Boot | 4.0.8，沿用当前工程 |
| MyBatis Starter | 4.0.1，匹配 Spring Boot 4 |
| Maven | 使用仓库 Maven Wrapper 3.10.0，避免三人使用不同 Maven |
| MySQL | 8.0.16 或更高的 8.0.x，使用 utf8mb4；8.0.16 起执行 CHECK 约束 |
| 模板 | Thymeleaf，版本由 Spring Boot BOM 管理 |
| Web API | Jakarta Servlet；新增代码禁止混入 javax.servlet |
| 演示与自动测试 | H2 MySQL 兼容模式，仅显式 demo profile 使用 |
| 默认端口 | 28089，可通过 SERVER_PORT 改写 |
| 显示名称 | 01电商系统 |
| 技术标识 | artifactId=01-ecommerce-system；数据库=mall_01；包=com.team.team_work |

Spring Boot 4 和 MyBatis 4 的官方兼容关系见参考项目说明。任务书的 Java 8 版本要求已按项目负责人本次指示调整；应在课程报告中说明此差异。

## 在 IDEA 导入

1. 打开当前仓库根目录的 `pom.xml`，作为 Maven 项目导入。
2. File → Project Structure → Project SDK 设为 JDK 17。
3. Settings → Build Tools → Maven 选择 Maven Wrapper；Runner JRE 设为 17。
4. 切换 `feature/member-a`，刷新 Maven 依赖。
5. 原有启动类 `TeamWorkApplication` 保留，避免已有 IDEA 运行配置失效。应用显示名称仍为“01电商系统”。

在终端确认：

```powershell
java -version
.\mvnw.cmd -version
git branch --show-current
```

## MySQL 初始化与启动

不要在已有生产库执行课程初始化。在本机 MySQL 使用数据库工具执行：

```sql
CREATE DATABASE IF NOT EXISTS mall_01 CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

SQL 文件位于 `database/create-database.sql`。应用账号需有本开发库的建表、读写权限；建库由有权限的本机账号完成，不在应用中自动创建数据库。

配置本机连接（每台电脑使用自己的密码，不提交到 Git）：

```powershell
$env:JAVA_HOME = '你本机的 JDK 17 目录'
$env:DB_USERNAME = '你的 MySQL 开发账号'
# 在本机交互读取密码，避免把明文写入 PowerShell 命令历史。
$securePassword = Read-Host 'MySQL 密码' -AsSecureString
$pointer = [Runtime.InteropServices.Marshal]::SecureStringToBSTR($securePassword)
try { $env:DB_PASSWORD = [Runtime.InteropServices.Marshal]::PtrToStringBSTR($pointer) }
finally { [Runtime.InteropServices.Marshal]::ZeroFreeBSTR($pointer) }
.\mvnw.cmd spring-boot:run '-Dspring-boot.run.profiles=init'
```

默认连接 `localhost:3306/mall_01`，其他地址可设置 `DB_URL`。IDEA 可在运行配置的环境变量中设置相同参数，Active profiles 首次填 `init`。

首次启动读取 `src/main/resources/db/V001__schema.sql` 和 `V001__seed.sql`。验证成功后停止应用，清除 `init` profile，正常运行：

```powershell
.\mvnw.cmd spring-boot:run
```

初始化不覆盖已有同 ID 数据，也不迁移已存在但字段不符的旧表。结构已漂移时应先备份、核对差异、提供 V002 增量脚本，禁止删除旧表以求启动成功。

## 访问与验收

| 地址 | 第一周行为 |
| --- | --- |
| http://localhost:28089/ | 商城启动页，从数据库读取初始化商品 |
| http://localhost:28089/admin | 后台环境入口，显示版本及数据量，无管理操作 |
| http://localhost:28089/login | 用户第二周开发项说明，无登录表单 |
| http://localhost:28089/api/environment | JSON 结构版本、框架版本、分类商品计数 |
| http://localhost:28089/test-db | 保留的数据库连通性接口，返回统一 JSON |

另开终端执行（Windows PowerShell 5.1 若中文显示异常，可在 PowerShell 7 执行）：

```powershell
pwsh -File .\scripts\Test-Environment.ps1
```

成功只代表当前电脑通过，把各自结果与截图填写到测试验收记录，三台电脑均使用 V001 才算团队环境验收完成。

## 无 MySQL 时的临时演示

```powershell
.\scripts\Start-Demo.ps1
# 另开终端
pwsh -File .\scripts\Test-Environment.ps1 -ExpectedDatabase 'H2 临时演示'
```

H2 不依赖本机 MySQL 密码，停止进程后数据清空。它用于页面演示和自动回归，不替代三台电脑 MySQL 的验收。

## 构建与检查

```powershell
.\mvnw.cmd -B clean verify
java -jar .\target\01-ecommerce-system-0.0.1-SNAPSHOT.jar --spring.profiles.active=demo
```

自动测试使用随机端口，不会占用正在运行的 28089。正式启动不要使用 demo profile。

## 常见问题

- 端口占用：使用 `$env:SERVER_PORT='28090'`，检查脚本加 `-BaseUrl http://localhost:28090`。
- Access denied：核对当前终端 / IDEA 的 DB_USERNAME、DB_PASSWORD；不会从 Git 获取密码。
- Unknown database：先建 `mall_01`；SQL 初始化只建表，不建数据库。
- Table not found / 环境接口 503：首次加 `init` profile；核对目标数据库，错误接口不暴露连接与堆栈。
- UnsupportedClassVersionError：Maven 和 IDEA 都使用 JDK 17，不能继续使用任务书原来的 JDK 8。
- Mapper 查询失败：刷新依赖并检查 `mapper/memberA/EnvironmentMapper.xml` 已进入构建产物。
- 脚本无法执行：可复制其中命令到终端执行，无需修改系统全局执行策略。
