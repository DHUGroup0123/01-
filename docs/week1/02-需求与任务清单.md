# 01电商系统 需求与任务清单

## 功能需求与验收

| 编号 | 需求 | 负责人 | 计划 | 可检查验收点 |
| --- | --- | --- | --- | --- |
| ENV-01 | 固定 Java 17、Boot 4、构建与本地配置 | A 牵头，ABC 执行 | 第1周 | 三机环境检查通过，不提交数据库密码 |
| ENV-02 | 数据初始化、表关系、接口与状态基线 | A 牵头，BC 复核 | 第1周 | V001 可重复初始化，字段与约定可查 |
| ENV-03 | 前后台入口可访问 | A 提供环境页，B 接续后台 | 第1周 | / 与 /admin 返回200且能读库 |
| USR-01 | 注册、验证码登录、退出 | A | 第2周 | 重复账号被拒，验证码过期和错误被拒，退出后会话失效 |
| USR-02 | 资料与收货地址维护 | A | 第2周 | 参数校验、默认地址唯一、仅操作本人数据 |
| USR-03 | Session 登录拦截 | A | 第2周 | 个人、购物车、订单未登录不能访问，API返回401 |
| MALL-01 | 首页轮播、分类导航、热销新品推荐 | A，B供数据 | 第2周 | 只展示有效配置和上架商品，缺图可回退 |
| MALL-02 | 关键词、分类、排序、分页、商品详情 | A，B供商品字段 | 第2周 | 参数有界，SQL参数化，下架不展示 |
| ADMIN-01 | 管理员登录与资料维护 | B | 第2周 | 登录鉴权、禁用管理员不可进入 |
| PROD-01 | 分类、商品、上下架、图片、轮播配置 | B | 第2周 | 数据保存正确，图片类型与大小校验 |
| ADMIN-02 | 会员禁用与解禁 | B | 第2周 | 禁用用户的后续受保护请求被拒绝 |
| CART-01 | 加购、改数量、删除 | C | 第2周 | 只能操作本人购物车，数量1至99 |
| ORDER-01 | 结算、生成订单、列表与详情 | C | 第2周 | 服务端计价、地址归属、库存原子扣减 |
| ORDER-02 | 支付演示、取消、确认收货 | C | 第3周 | 只允许指定状态转换，重试不能重复扣减或回滚 |
| ORDER-03 | 后台订单查询、配货、出库、关闭 | C，B集成后台 | 第3周 | 管理权限校验、非法状态拒绝 |
| QA-01 | 主流程与异常联调 | C 牵头，AB修复 | 第3周 | 无库存、下架、无地址、越权、非法状态均有记录 |
| REL-01 | 打包部署、报告和演示 | B部署，A报告，C回归 | 第4周 | 新库按说明启动，演示与报告一致 |

## 非功能与范围

项目以可运行的课程单体应用为目标；采用 Controller / Service / Mapper / Entity / DTO 分层。金额用 BigDecimal / DECIMAL，SQL 使用 MyBatis 参数绑定，会话中不存密码。图片和业务数据由本项目自行准备。支付仅为系统内演示，不调用真实支付渠道。

第一周不交付完整第二周模块，不宣称已完成三机验收，也不把 A 的草案当作其他成员已确认的接口。
