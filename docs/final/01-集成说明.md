# 01电商系统 本地完整版本

修改日期：2026-11-05。开发版本固定Spring Boot4.0.8、Java17、MyBatis4.0.1。Servlet与Resource注入迁移为Jakarta，JSON使用Jackson3，上传目录使用可配置本地路径。

成员A继续使用前两周的控制器、服务、Mapper、DTO、模板、CSS和JS，调整数据字段适配，不另起一套A模块。商城和用户接口继续由memberA维护。后台与交易模块与其整合，页面保持原有浅色与绿色主题。

初始化文件为 `src/main/resources/mall_schema.sql`。数据库由 `DB_NAME` 指定，默认使用 `mall_01_full`。应用启动时导入空库，已有表时跳过初始化。手动导入工具会核对 `database/schema.sha256`。9 张项目表使用 `tb_mall_` 前缀。

为符合原表结构，账号使用手机号；收货信息使用一条100字地址；密码兼容32位MD5字段。原先PBKDF2编码和独立多地址模型不适用于当前SQL，历史mall_01数据不被本次初始化改写。商城价格、上下架值、订单状态与数据库原字段一致。

集成中增加了用户归属与支付归属校验、写请求CSRF校验、购物车数量校验、库存逐项校验与订单事务。演示支付只有登录用户可以操作自己的待支付订单，不产生真实扣款。订单配货后才能出库，出库后才能确认收货。

后台模板、脚本和 Mapper 文件使用项目命名。演示轮播使用本地素材并链接到商品搜索，缺失的商品图片使用项目占位图。原有许可证及版权声明保留。

完整版本包含项目源码、初始化 SQL、启动说明和最终验收记录。
