# 成员 B 接口与数据约定

这些是本次实现使用的明确契约，尚不等同于 A/C 已完成适配。没有修改公共实体或 A/C 代码。

## 共享字段与表

沿用参考项目命名：`tb_newbee_mall_goods_category`、`tb_newbee_mall_goods_info`、`tb_newbee_mall_admin_user`、`tb_newbee_mall_carousel`、`tb_newbee_mall_index_config`、`tb_newbee_mall_user`。字段详见 `src/main/resources/memberB/schema.sql`。它是新开发库初始化脚本，不是现存 newbee-mall 数据库的原样迁移脚本。

- 分类：`parent_id=0` 为根，`category_level=1/2/3`，商品只关联第三级。`is_deleted=0` 可用、`1` 删除。
- 商品：`goods_sell_status=0` 上架、`1` 下架，与参考项目一致。新建商品默认下架。缺货不能上架。
- 金额：`original_price`、`selling_price` 使用 `DECIMAL(10,2)`，单位元，禁止使用浮点数计算。与参考项目整数价格存储存在差异，A/C 读取时使用 BigDecimal。
- 商品 `version` 用于乐观锁，后台编辑与库存变更均递增。A/C 如果直接写商品表也必须遵守该规则，建议直接调用下述库存服务。
- 首页类型：`config_type=3` 热销、`4` 新品、`5` 推荐。轮播/配置 `is_deleted=0` 启用、`1` 停用。启用配置只允许关联有库存的上架商品。
- 会员：`locked_flag=0` 正常、`1` 禁用。B 只维护该状态；A 在登录和每次会话请求时调用 `MemberAccessService.requireActive(userId)`，才能同时阻止已登录的禁用会员继续操作。
- 管理员 Session key 是 `memberB.admin`，不会与 A 的用户会话字段混用。会话中不存密码，数据库每次校验锁定状态及凭据版本。

已有参考项目数据库通常没有 `version` / `credential_version` / B 去重表，而且可能使用不同价格类型。不要直接在组数据库运行本脚本以尝试“自动升级”；应由组内审核后另做迁移。

## A 调用的读取服务

可注入 `CatalogService`：`categories()`、`tree()`、`products(q, categoryId, status, page, size)`、`product(goodsId)`。商城展示显式传入 `status=0`，详情读取后同样检查上架状态，不能直接把后台读取接口暴露给匿名用户。

首页配置由 `OperationsService.configs()`、`carousels()` 读取；A 应过滤 `isDeleted=0`，并对商品状态再校验。商品详情当前按纯文本处理，不使用 `th:utext` 或 `innerHTML` 插入详情内容。

## C 调用的库存服务

`InventoryService.reserve(orderLineId, goodsId, quantity)` 和 `release(orderLineId, goodsId, quantity)` 都是事务方法。C 应在自己的订单创建/取消事务内调用，使订单状态与库存更新同一事务提交。

- `orderLineId` 是全局稳定、唯一的订单明细业务编号，1至90位字母、数字、下划线或连字符。相同编号同一操作重试返回现有结果。
- 预占使用条件更新：商品上架且库存足够才扣减。库存不足、下架或不存在返回业务冲突。
- 归还必须已有匹配预占记录，商品、数量必须相同；重复归还不会再增加库存。
- 同编号更换商品/数量拒绝；同一明细取消后不能再次用原编号预占。新订单使用新明细编号。
- B/C 写操作统一先锁 `tb_member_b_guard` 的单行，再修改目录/库存及写业务记录。课程项目采用这一简单串行化方案保证层级校验、配置校验和重试结果一致；大规模吞吐不是本次目标。组内直接绕过服务写库将绕过这些保护。

## HTTP 接口

所有写请求需要当前 Session 的 `X-CSRF-Token`。除登录、退出和内容寻址的图片上传外，还必须提供16至100位 `Idempotency-Key`（字母数字、下划线、连字符）。同一个管理员、同一个 key、相同路径和请求体返回原结果；key 对应不同意图返回409。业务写入与 JSON 回执同一事务提交，不假设超时即失败。

| 路径 | 方法 | 用途 |
| --- | --- | --- |
| `/admin/b/login` | GET / POST | 登录页及 JSON 登录 |
| `/admin/b/captcha` | GET | 有效期两分钟、使用一次的图形验证码 |
| `/admin/b/api/profile` | GET / POST | 当前管理员资料 |
| `/admin/b/api/password` | POST | `oldPassword`、`newPassword` |
| `/admin/b/api/logout` | POST | 退出当前会话 |
| `/admin/b/api/categories` | GET / POST | 分类树及新增/修改 |
| `/admin/b/api/categories/{id}` | DELETE | 删除空分类 |
| `/admin/b/api/products` | GET / POST | 分页查询及新增/编辑 |
| `/admin/b/api/products/{id}` | GET | 商品详情 |
| `/admin/b/api/products/{id}/status` | POST | `status`、当前 `version` |
| `/admin/b/api/carousels` | GET / POST | 轮播列表及新增/修改 |
| `/admin/b/api/carousels/{id}` | DELETE | 删除轮播 |
| `/admin/b/api/configs` | GET / POST | 首页配置列表及新增/修改 |
| `/admin/b/api/configs/{id}` | DELETE | 删除配置 |
| `/admin/b/api/members` | GET | 会员分页查询 |
| `/admin/b/api/members/{id}/status` | POST | `locked=0/1` |
| `/admin/b/api/upload` | POST multipart | 字段 `file`，返回 `data.url` |

结果格式为 `{resultCode,message,data}`，成功 HTTP 200。分页数据含 `rows`、`records`、`page`、`size`。HTTP 400 参数错误、401未登录、403校验失败/禁用、404不存在、409冲突、429登录失败过多。

上传只接受真实 PNG/JPEG/GIF，5MB以内、每边≤4096、总像素≤1600万，重新编码后按 SHA-256 保存 PNG。客户端文件名不参与路径拼接。同图重传使用同一地址。部署时还应显式设置 Spring multipart 上限；公共配置默认未改。

去重表的回执可能包含修改前业务数据，管理员权限应限制数据库访问。为避免重试重新执行，不自动删除回执；清理前须约定请求保留时间并保留业务唯一约束。该方案没有邮件、短信或真实支付接口。
